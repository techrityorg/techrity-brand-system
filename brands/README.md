# Child Brands

These brands belong to the **[Techrity](../README.md)** parent brand system, but each has its own visual identity. Each folder mirrors the parent's layout (`logos/`, `design-tokens/`, `public/`, plus its own extras).

| Brand | Folder | Role | Token prefix |
|-------|--------|------|--------------|
| Tech for Good | [tech-for-good/](tech-for-good/) | Flagship annual conference: the ecosystem's **Amplify** stage | `--t4g-` |
| Made For Good | [made-for-good/](made-for-good/) | CSR, merch and storytelling movement (formerly MerchByTechrity) | `--m4g-` |

All other Techrity programmes use the parent system. A new child folder is only justified when a programme has an approved identity of its own; the Ecosystem Transformation brief warns that letting programmes grow their own identities fragments the ecosystem.
